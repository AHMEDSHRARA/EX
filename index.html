Access & Privacy
Opening the dashboard and switching to Admin mode
  1. Open the dashboard — from your device or Power BI.
  2. Click Tab 05 — Weekly Execution in the left navigation.
  3. Locate the ROLE dropdown in the top toolbar (shows "Viewer" by default).
  4. Select Admin — a password dialog appears inside the dashboard.
  5. Type the password (shown as ••••••) and press Confirm or Enter.
  6. The Role field now shows Admin and all Edit buttons become visible.
🔐 Password Privacy Rules
  • Password is always masked — shows as ••••••••, never visible.
  • Never written in any document, email, screenshot, or log.
  • Communicated verbally only, person-to-person.
  • All password use is recorded in the Audit Trail.

3
Cloud Connection
Connect → Verify → Pull → Edit → Push → Backup
  1. Click the State button in the top toolbar.
  2. Select Cloud sync settings… and enter the admin password.
  3. Verify Provider, URL, and API Key are filled in.
  4. Click Save & connect then Test connection.
  5. Wait for ✅ confirmation before proceeding.
🟢 Synced
Safe to pull and push
🔵 Syncing…
Wait — do not edit yet
🟠 Pending
Push before leaving
🔴 Offline / Error
Check internet, click Push now
⛔ Rule: Do not begin editing until status shows 🟢 Synced.
4
Pull Latest Data
Always pull before editing — mandatory
⛔ Mandatory: Pull before making any changes. Skipping this may overwrite another user's work.
  1. Open Cloud sync settings → click Sync now (pull).
  2. Wait for ✓ Synced status.
  3. Note the Current revision number — confirms you have the latest version.
  4. Confirm Pending: no before proceeding.
5
Week Selection
Choosing the correct reporting week
  1. Select Program → Project → Contract using the three dropdowns in the toolbar.
  2. Set the Reporting Week using the week field or ← → arrows. Click Current for this week.
  3. Confirm the week shown at the top of the page (e.g., 2026-W35).
Compare Weeks: Click Compare to view 2–3 weeks side-by-side (Progress %, narratives, item counts). Maximum 3 weeks at once.
6
Copy / Load Weekly Data
Start from scratch or copy from a previous week
  1. Ensure you are on the target week (e.g., W35).
  2. Click ⎘ Copy Prev Week in the toolbar.
  3. Confirm the Source Week (W34) and Target Week (W35).
  4. Select which sections to copy using the checkboxes.
  5. Click Copy & create draft.
  6. Review copied data — the source week (W34) is never modified.
⚠️ Copying creates a draft only. The source week's approved record is preserved.
7
Edit Each Section
How to update data in every card
  1. Find the section card (e.g., Milestones, Challenges, Lookahead).
  2. Click Edit — the card opens in edit mode.
  3. Update the data. For text fields: one point per line. For tables: add/edit/delete rows.
  4. Click Save. A Saved ✓ toast confirms cloud sync.
  5. To remove a section's data: click ✕ Clear → type CLEAR to confirm.

8
User Identification
Every change is linked to your name
  1. In the Tab 5 toolbar, check the USER field.
  2. If it shows Anonymous — type your name and press Enter.
  3. Every edit now records: Your name · Date · Time · Week · Section · Revision.

Before Leaving Tab 5
Checklist — complete before switching tabs or closing
All section edits are saved — no open Edit mode
Status chip shows 🟢 Cloud · Synced
Cloud sync settings shows Pending: no
Last sync time is within the last 2 minutes
If Pending: yes — click Push now and wait for Saved ✓ before leaving.
11
Push Data to Cloud
Final sync after all edits are complete
  1. Open State → Cloud sync settings…
  2. Click ⭱ Push now.
  3. Wait for 🟢 Synced status.
  4. Confirm revision number has increased (e.g., r451 → r452).
  5. Confirm Pending: no.
12
Verification
Check data integrity before creating a backup
Correct week selected (e.g., 2026-W35)
All mandatory sections have data entered
Milestone % Plan and % Actual are filled in
No section is still in Edit mode
Health indicators are set correctly
Site photos uploaded and captioned (if available)
Cloud sync: Pending: no
USER field shows your name — not Anonymous
13
Backup
Create a local copy after completing the weekly update
  1. In the Tab 5 toolbar, click Backup.
  2. File downloads automatically: weekly_backup_2026-09-09.json
  3. Save in a secure location (OneDrive, shared drive).
Backup includes: All weekly data · All weeks · Milestone records · Photos (Base64) · Captions · Comments · Audit history
